# Smoke evidence (local + interim HTTPS)

Generated by `npm run smoke:company-plugins-api` and manual interim tunnel checks.

- `LATEST.md` — human-readable local listening acceptance summary (committed).
- `plugins-api-*.json` — optional captured response bodies (may be gitignored if large).
- `interim-https-*.json` / `interim-https-headers.txt` — **public HTTPS** evidence via
  `cloudflared` quick tunnel → `wrangler dev --local`. **`durable: false`** —
  not a company apex. Do not pin AI Buddy `company-store` constants to the
  trycloudflare hostname.

Durable public HTTPS URLs and the secrets-gated deploy workflow belong in
`docs/company-fork-deploy.md` once Cloudflare credentials exist.
